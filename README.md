## Question 29

**Title:** Debugging Maximum–Minimum Finder Code (Improper Initialization for Negative Inputs)

### Objective

Debug the given maximum–minimum finder program, identify the root cause of the error, correct the implementation to handle positive, negative, and mixed inputs, and analyze its time complexity.

### Programming Language

- Python 3

### Algorithm

1. Read the array elements from the user.
2. Initialize both minimum and maximum with the first element.
3. Traverse the remaining elements one by one.
4. Update the minimum if a smaller element is found.
5. Update the maximum if a larger element is found.
6. Display the minimum and maximum values.

### Time Complexity

- **O(n)**

### Space Complexity

- **O(1)**

### Files Included

- **Source_Code/** – Contains the Python source code.
- **Report/** – Contains the report with screenshots, output, analysis, documentation, and complexity analysis.
